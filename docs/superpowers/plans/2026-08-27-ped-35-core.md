# PED-35 Core Emulation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the deterministic DMG CPU, memory bus, cartridge controllers, timers, interrupts, and source-aware joypad core needed to unblock PPU, APU, desktop-runtime, and compatibility work.

**Architecture:** A concrete `GameBoy<C: Clock + Send>` implements the frozen `EmulatorCore` trait and owns a Sharp LR35902 CPU plus a machine bus. CPU memory accesses advance the bus in four-T-cycle machine cycles; the bus owns cartridge, timer, interrupt, joypad, DMA, and register-only `Send` video/audio devices behind stable private traits so PED-36 and PED-49 can replace only those devices. Cartridge loading is transactional, mapper RTC reads use the injected clock, and no core code performs filesystem, network, wall-clock pacing, Tauri, React, or platform-audio work.

**Tech Stack:** Rust stable edition 2024, Cargo workspace, Rust standard library, `sha2` for stable ROM identities, built-in Rust tests, explicitly provisioned Blargg ROMs, and pinned MIT-licensed Mooneye ROMs

**Spec:** `docs/superpowers/specs/2026-08-27-game-boy-emulator-design.md`

## Global Constraints

- Target original DMG hardware and use T-cycles as the only core timing unit: `DMG_CLOCK_HZ = 4_194_304` and `T_CYCLES_PER_M_CYCLE = 4`.
- Accept DMG cartridges and dual-mode DMG/GBC cartridges in DMG mode; reject header byte `0x0143 == 0xC0` before changing the loaded machine.
- Support cartridge type bytes `0x00`, `0x08`-`0x09`, `0x01`-`0x03`, `0x0F`-`0x13`, and `0x19`-`0x1E`; return `CoreError::UnsupportedMapper(type_byte)` for every other type.
- Preserve the frozen methods and types in `crates/gb-core/src/contracts/**`; PED-35 adds the concrete `GameBoy<C>` but does not rename or change an `EmulatorCore` signature.
- The desktop emulation thread consumes `EmulatorCore + Send`; therefore `GameBoy<C>` exists only for `C: Clock + Send`, and every owned trait object is `Send` through its device or mapper supertrait.
- Keep PPU pixel generation in PED-36 and APU synthesis in PED-49. PED-35 owns their CPU-visible address ranges, per-machine-cycle tick calls, interrupt return path, `Frame`/`AudioBatch` hand-off points, and OAM DMA scheduling.
- `gb-core` must contain no Tauri, React, filesystem, network, Tokio, or platform-audio dependency and must retain `#![forbid(unsafe_code)]`.
- Input sources remain independent; updating or clearing one `InputSourceId` recomputes the union and never releases another source's buttons.
- ROM binaries remain ignored and uncommitted. Ordinary install, build, test discovery, and application startup perform no ROM download.
- PED-35 may enter `Done` only after the seven pinned Mooneye tests and the two checksum-matched, user-provisioned Blargg tests pass; absence of the local-only Blargg files leaves the issue `In Progress` without authorizing a download.
- Every implementation unit follows red-green-refactor and ends in the commit named in that task.
- `Cargo.lock` is a shared coordinator-owned file. PED-35 may cause Cargo to refresh it locally while resolving `sha2`, but this lane never stages or commits it; the coordinator reconciles and commits the shared lockfile separately.

```rust
pub struct GameBoy<C: Clock + Send> {
    clock: C,
    sample_rate: NonZeroU32,
    cpu: Cpu,
    bus: Option<MachineBus>,
    inputs: InputMatrix,
}

impl<C: Clock + Send> GameBoy<C> {
    #[must_use]
    pub fn new(clock: C, sample_rate: NonZeroU32) -> Self {
        Self {
            clock,
            sample_rate,
            cpu: Cpu::post_boot_dmg(),
            bus: None,
            inputs: InputMatrix::default(),
        }
    }
}

impl<C: Clock + Send> EmulatorCore for GameBoy<C> {
    fn load_rom(&mut self, rom: &[u8], persisted: Option<&BatteryState>) -> Result<CartridgeMetadata, CoreError> {
        let now = self.clock.unix_seconds();
        let cartridge = Cartridge::load(rom, persisted, now)?;
        let metadata = cartridge.metadata().clone();
        let mut bus = MachineBus::new(cartridge, self.sample_rate, now);
        bus.set_joypad_state(self.inputs.effective());
        self.cpu = Cpu::post_boot_dmg();
        self.bus = Some(bus);
        Ok(metadata)
    }

    fn reset(&mut self) -> Result<(), CoreError> {
        let bus = self.bus.as_mut().ok_or(CoreError::NotLoaded)?;
        bus.reset(self.clock.unix_seconds(), self.inputs.effective());
        self.cpu = Cpu::post_boot_dmg();
        Ok(())
    }

    fn run_cycles(&mut self, cycle_budget: u32) -> Result<RunOutcome, CoreError> {
        let bus = self.bus.as_mut().ok_or(CoreError::NotLoaded)?;
        let mut executed = 0_u32;
        while executed < cycle_budget {
            bus.set_unix_seconds(self.clock.unix_seconds());
            let next = self.cpu.next_step_t_cycles(bus)?;
            if next == 0 || next > cycle_budget - executed { break; }
            let result = self.cpu.step(bus)?;
            debug_assert_eq!(result.t_cycles, next);
            executed += result.t_cycles;
        }
        Ok(RunOutcome::new(executed, bus.frame_ready(), bus.stereo_frames_available()))
    }

    fn set_input(&mut self, source: InputSourceId, state: JoypadState) {
        self.inputs.set(source, state);
        if let Some(bus) = self.bus.as_mut() { bus.set_joypad_state(self.inputs.effective()); }
    }

    fn clear_input_source(&mut self, source: InputSourceId) {
        self.inputs.clear(source);
        if let Some(bus) = self.bus.as_mut() { bus.set_joypad_state(self.inputs.effective()); }
    }

    fn take_frame(&mut self) -> Option<Frame> {
        self.bus.as_mut().and_then(MachineBus::take_frame)
    }

    fn drain_audio(&mut self) -> AudioBatch {
        match self.bus.as_mut() {
            Some(bus) => bus.drain_audio(),
            None => AudioBatch::empty(self.sample_rate),
        }
    }

    fn battery_state(&self) -> Option<BatteryState> {
        self.bus.as_ref().and_then(|bus| bus.battery_state(self.clock.unix_seconds()))
    }
}
```

`load_rom` builds and validates a candidate `Cartridge` before replacing `cpu/bus`; successful load starts at post-boot DMG state. `run_cycles` snapshots the clock, peeks decode metadata plus current flags/pending interrupt to obtain the exact next-step cost, executes only when that cost fits the remaining budget, and asserts `StepResult.t_cycles` equals the estimate; STOP with no Joypad wake condition returns immediately. `RunOutcome` reports actual executed T-cycles, `VideoDevice::frame_ready()`, and the audio device's currently drainable stereo-frame count. `reset` calls `MachineBus::reset(clock.unix_seconds(), inputs.effective())`, retains mapper RAM/RTC, and restores volatile CPU, timer, interrupt, DMA, serial, video-register, and audio-register state.
