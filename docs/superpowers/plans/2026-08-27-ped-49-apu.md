# PED-49 DMG APU and Desktop Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the DMG APU, bounded stereo PCM production, and a portable desktop audio output whose audio-buffer occupancy provides stable pacing and whose pause/restart/close lifecycle cannot retain stale samples or an output device.

**Architecture:** `gb-core` owns deterministic DMG register behavior, four sound channels, frame-sequencer timing, mixing, high-pass filtering, rational sample generation, and a bounded platform-neutral PCM buffer. `apps/desktop/src-tauri/src/audio` owns a CPAL `=0.18.2` CoreAudio/WASAPI adapter backed by a lock-free `ringbuf` `=0.5.1` SPSC queue; the audio callback only copies already-produced `f32` samples or silence. PED-36 and PED-49 consume one coordinator bootstrap in three commits: four undeclared roots, then core `mod ppu;`/`mod apu;` plus desktop `mod video;`/`mod audio;` and manifest, then only `Cargo.lock`; shared core integration runs strictly PED-36 video first and PED-49 APU/T-cycle second.

**Tech Stack:** Rust stable edition 2024, Rust standard library, CPAL `=0.18.2` with `default-features = false`, ringbuf `=0.5.1`, CoreAudio on `aarch64-apple-darwin`, WASAPI on `x86_64-pc-windows-msvc`, Cargo tests, checksum-gated local-only Blargg DMG sound ROM

**Spec:** `docs/superpowers/specs/2026-08-27-game-boy-emulator-design.md`

## Global Constraints

- Target original DMG hardware, macOS Apple Silicon (`aarch64-apple-darwin`), and Windows x64 MSVC (`x86_64-pc-windows-msvc`).
- Preserve the frozen public `EmulatorCore` and `AudioBatch` contracts; `AudioBatch` remains non-platform-specific interleaved stereo `f32` with a non-zero sample rate.
- Keep `gb-core` free of Tauri, React, filesystem, network, CPAL, ringbuf, platform-audio, sleep, and wall-clock pacing dependencies; retain `#![forbid(unsafe_code)]`.
- Use T-cycles throughout the APU. `DMG_CLOCK_HZ` remains `4_194_304`; channel timers and sample generation advance only from core-supplied T-cycles.
- Clock the DMG frame sequencer from an APU-owned divider mirror on every falling edge of bit 12. `Apu::new` and `reset` initialize it to `0xabcc`, exactly matching `Timer::default`; `AudioDevice::tick(t_cycles)` advances it and the existing `AudioDevice::write(0xff04, 0)` path notifies it of a CPU `DIV` reset. Do not add a trait method or an independent wall-clock 512 Hz timer.
- Implement channels 1 and 2 pulse, channel 3 wave, channel 4 noise, length counters, volume envelopes, channel-1 sweep, NR50/NR51 routing, NR52 power/status, wave RAM, and DMG-visible register quirks required by Blargg `dmg_sound`.
- Generate deterministic stereo PCM at the constructor-supplied rate with a rational integer accumulator; never derive core samples from host callback timing.
- Bound the core PCM buffer at `4_096` stereo frames. On core overflow, discard the oldest complete stereo frame and increment a test-visible counter; never split a left/right pair.
- Use CPAL `=0.18.2` exactly with `default-features = false` and ringbuf `=0.5.1` exactly: default backends are CoreAudio on macOS and WASAPI on Windows; do not enable optional ASIO, JACK, ALSA, PipeWire, PulseAudio, or realtime features.
- Select an `F32`, two-channel output configuration explicitly through `supported_output_configs()`. Prefer `48_000 Hz` with `try_with_sample_rate`, otherwise use `try_with_standard_sample_rate`; never assume the default sample format, channel count, or sample rate.
- CPAL `0.18.2` streams are stopped after construction. Call `StreamTrait::play()` explicitly, retain sole ownership of the non-`Clone` stream, and drop it on ROM close, replacement, shutdown, or terminal stream failure.
- Use a `ringbuf::HeapRb<f32>` split into one producer and one consumer. The CPAL callback performs no allocation, blocking send, mutex acquisition, logging, format conversion, or emulator call.
- Desktop watermarks are `40 ms` low, `80 ms` target, `120 ms` high, and `160 ms` hard capacity at the negotiated sample rate. Queue counts always mean stereo frames even though the ring stores interleaved samples.
- Audio occupancy is the primary running-state pacing signal. If audio cannot initialize or later becomes unusable, keep video/input running and fall back to the monotonic `16_743 µs`/`70_224`-T-cycle cadence.
- Pause stops core advancement and sample production, leaves the callback running in silent mode long enough to acknowledge and clear the queue epoch, and invalidates queued audio. Restart waits for that acknowledgment before priming new audio. Close/replacement/shutdown pause and drop the stream plus both queue halves.
- Never commit, cache, publish, or automatically download Blargg ROMs. The only APU compatibility asset is user-provisioned, local-only, SHA-256 verified before execution, and ignored by ordinary tests.
- Every direct tool command is prefixed with RTK. On POSIX/macOS, shell scripts, checksum pipelines, environment-variable commands, and platform probes use `rtk run '...'`. The Windows x64 runner must provide `rtk.exe`; invoke PowerShell through `rtk.exe proxy powershell` and Cargo through `rtk.exe cargo` so execution remains native without assuming a POSIX shell. `Cargo.lock` is coordinator-owned, is never staged by a lane, and is committed alone.

- [ ] **Step 2: Implement the eight-step dispatcher**

Initialize/reinitialize `divider_mirror` to `0xabcc`. On every T-cycle, capture its old bit 12, increment with wrapping arithmetic, and dispatch one frame step only for a high-to-low transition. Therefore the first post-boot/reset falling edge occurs after `0xc000 - 0xabcc = 5_172` T-cycles. `write(0xff04, 0)` performs the same edge test before zeroing the mirror. At step `0`, clock all enabled lengths; step `2`, clock lengths then channel-1 sweep; step `4`, clock lengths; step `6`, clock lengths then sweep; step `7`, clock pulse/noise envelopes. Increment modulo eight only after dispatch. No other step clocks a unit.
