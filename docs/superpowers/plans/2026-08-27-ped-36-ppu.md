# PED-36 DMG PPU and Desktop Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement DMG LCD timing, background/window/sprite rendering, stable `160 x 144` raw RGBA frame delivery, and aspect-ratio-preserving nearest-neighbor presentation for DMG and dual-mode cartridges running in DMG mode.

**Architecture:** A crate-private `Ppu` replaces PED-35's register-only `VideoRegisters` behind the existing `VideoDevice: Send` seam. It advances one T-cycle at a time through DMG LCD modes, renders one completed scanline from VRAM/OAM state, publishes one overwrite-bounded immutable `Frame` at VBlank, and requests VBlank/STAT through the existing interrupt fan-in. The desktop keeps the already-frozen raw binary frame packet and acknowledgment backpressure, but moves video-specific packet/queue/presentation code into owned video modules; existing bus, emulator-runtime, and composition files are integrated serially by the coordinator.

**Tech Stack:** Rust stable edition 2024, `gb-core`, Tauri 2 channels, React 19, TypeScript 7, Vitest 4, Testing Library, raw little-endian RGBA packets, SHA-256, Mooneye Test Suite, and dmg-acid2

**Spec:** `docs/superpowers/specs/2026-08-27-game-boy-emulator-design.md`
